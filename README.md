\# 🏠 HomeFix

\### Your home. Fixed in a flash.



HomeFix is a responsive \*\*home services UI/UX frontend prototype\*\* designed to make it easier for users to explore and request common home repair services through a clean, user-friendly interface.



> \*\*Note:\*\* This is a frontend demonstration project. Service requests and booking confirmations are simulated; no real technicians or bookings are provided.



\## ✨ Features



\- Responsive design for desktop and mobile screens

\- Home service categories:

&#x20; - Plumbing

&#x20; - Electrical

&#x20; - AC Repair

&#x20; - Appliance Repair

\- Search and filter service cards

\- Interactive booking modal with form validation

\- Demo booking confirmation

\- “Why HomeFix” section highlighting trust and clear expectations

\- Simple three-step service process

\- Smooth hover effects and modern UI styling



\## 🛠️ Technologies Used



\- HTML5

\- CSS3

\- JavaScript

\- Google Fonts — Inter

&#x20;  ```bash

&#x20;  cd HomeFix

&#x20;  ```

\## 🎯 Project Goal



The goal of HomeFix is to explore how thoughtful UI/UX design can simplify the process of finding and requesting home repair services, with a focus on usability, clarity, and responsive design.
